SONDADOR DE BUSCA

Roda na busca da Shopee como comprador e revela quem apareceu, em que posição, anúncio ou orgânico, e o que separa você dos concorrentes do topo.

PASSO 1 · ABRA A BUSCA

No navegador, abra shopee.com.br e pesquise o termo que você quer investigar (ex: "vaso decorativo preto"). Deixe a página de resultados carregar até o fim (role um pouco pra baixo pra carregar mais produtos).

PASSO 2 · ABRA O CONSOLE

Aperte F12 (ou botão direito → Inspecionar) e clique na aba Console. É uma área de texto onde dá pra colar comandos.

No celular não tem console — este passo é no computador. A versão da extensão (que roda no clique, sem console) vem depois; este script é pra você já ver o poder da ideia hoje.
PASSO 3 · COLE O SONDADOR

Cole o código abaixo no console e aperte Enter. Ele lê os resultados, monta uma tabela e marca em verde os seus produtos (você troca o nome da sua loja na primeira linha).

/* ===== SELLER.IA · SONDADOR DE BUSCA v2 ===== */
(async () => {
  const MINHA_LOJA = "colorindo_shop"; // nome ou parte do nome da SUA loja

  const url = new URL(location.href);
  const kw = url.searchParams.get("keyword") || "";
  if (!kw) { console.log("%cAbra uma pagina de RESULTADOS de busca primeiro.","color:#f5b041;font-size:14px"); return; }

  const api = `/api/v4/search/search_items?by=relevancy&keyword=${encodeURIComponent(kw)}&limit=60&newest=0&order=desc&page_type=search&scenario=PAGE_GLOBAL_SEARCH&version=2`;
  const r = await fetch(api, { headers: { "x-api-source": "pc", "x-shopee-language": "pt-br" }, credentials: "include" });
  const j = await r.json();
  const raw = j.items || [];
  if (!raw.length) { console.log("%cA busca voltou vazia — role a pagina e rode de novo.","color:#f5b041"); return; }

  // helper: acha um campo em qualquer nivel do objeto testando varios nomes
  const pick = (o, nomes) => {
    for (const n of nomes) {
      if (o[n] !== undefined && o[n] !== null) return o[n];
      if (o.item_basic && o.item_basic[n] !== undefined) return o.item_basic[n];
    }
    return undefined;
  };
  const num = v => (typeof v === "number" ? v : (v ? +v : 0));

  const items = raw.map((it, i) => {
    const b = it.item_basic || it;
    const precoRaw = pick(it, ["price","price_min","price_max"]);
    const preco = precoRaw ? (num(precoRaw)/100000).toFixed(2) : "?";
    const vendidos = num(pick(it, ["historical_sold","sold","global_sold_count","item_sold"]));
    const rat = pick(it, ["item_rating"]) || {};
    const ehAds = !!(pick(it, ["adsid","is_ads","ads_keyword_id"]) || it.ads_keyword_id);
    return {
      pos: i + 1,
      nome: (pick(it,["name","title"])||"").slice(0,45),
      loja: num(pick(it,["shopid"])),
      preco,
      vendidos,
      estrelas: rat.rating_star ? (+rat.rating_star).toFixed(2) : "-",
      avaliacoes: rat.rating_count ? (Array.isArray(rat.rating_count)? rat.rating_count[0] : rat.rating_count) : 0,
      tipo: ehAds ? "ADS" : "org",
      local: pick(it,["shop_location"]) || "-",
    };
  });

  console.log(`%cSELLER.IA · "${kw}" — ${items.length} resultados`,"color:#ff4d1c;font-size:16px;font-weight:bold");
  console.table(items);

  // resumo (so com os que tem preco/vendidos validos)
  const comPreco = items.filter(x=>x.preco!=="?").map(x=>+x.preco);
  const ads = items.filter(x=>x.tipo==="ADS").length;
  console.log("%c▼ Resumo","color:#7B2FFF;font-size:14px");
  console.log(`Anuncios no topo: ${ads} de ${items.length} · Organicos: ${items.length-ads}`);
  if (comPreco.length) console.log(`Preco medio da 1a pagina: R$ ${(comPreco.reduce((a,b)=>a+b,0)/comPreco.length).toFixed(2)}`);
  const top10 = items.slice(0,10);
  const vendTop = top10.map(x=>x.vendidos).filter(v=>v>0);
  if (vendTop.length) console.log(`Vendidos medios do TOP 10: ${Math.round(vendTop.reduce((a,b)=>a+b,0)/vendTop.length)}`);
  const meus = items.filter(x=>String(x.loja) && j.items.find((o,idx)=> idx===x.pos-1 && ((o.item_basic||o).shop_name||"").toLowerCase().includes(MINHA_LOJA.toLowerCase())));
  if (meus.length) { console.log(`%cSeus produtos nesta busca:`,"color:#2ecc71"); console.table(meus); }
  else console.log("%cNenhum produto seu no top 60 desta busca (ou ajuste MINHA_LOJA).","color:#7d8290");

  // diagnostico: se nome/preco vierem vazios, dumpa 1 item cru pra eu mapear
  if (items[0].nome==="" || items[0].preco==="?") {
    console.log("%cCampos vazios — me mande o objeto abaixo (clique com botao direito → Copy object):","color:#f5b041");
    console.log(raw[0]);
  }
})();
O QUE ELE REVELA
POSIÇÃO a ordem real de cada produto na busca
ADS vs ORG quem pagou pra estar ali e quem é orgânico
PREÇO de cada um + o preço médio da 1ª página
VENDIDOS quanto cada concorrente já vendeu
ESTRELAS avaliação e nº de reviews
VENDIDOS DO TOP 5 a barreira de entrada pro topo
Este é o protótipo da ideia. Quando virar parte da extensão, roda no clique (sem console), destaca seus produtos automático e cruza com o método: "pra entrar no top 5 dessa busca, o padrão é X vendidos e preço até R$Y — seu produto está em Z".

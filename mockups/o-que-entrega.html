02 AS NOTAS 61, 33 E 12 — EU ERREI

Chamei de "três notas". Abrindo o payload inteiro, não são notas.

"diagnosis_result_list": [
  { "result": 61 },
  { "result": 33 },
  { "result": 12, "content_quality": { ... } }
]

São três códigos de diagnóstico, não pontuações. A prova está no terceiro: quando o código é 12, vem junto o objeto content_quality com o checklist. Ou seja, result identifica qual é o problema, e alguns códigos trazem o detalhe anexado.

Este produto tem três diagnósticos simultâneos. Sabemos que 12 = qualidade de conteúdo. Os códigos 61 e 33 ainda não sabemos, porque vieram sem detalhe.

03 O ACHADO QUE ESTAVA ESCONDIDO NO MESMO PAYLOAD

is_new_product_period  = true
new_product_period_day = 90
task_deadline_day      = 69

Este produto está na janela de 90 dias de produto novo, e faltam 69 dias para o prazo das tarefas de qualidade. Ou seja: existe um relógio correndo, com prazo, e a única tarefa não cumprida é video_include.

Isso é acionável hoje: "faltam 69 dias da sua janela de produto novo, e falta só o vídeo para completar a qualidade." Prazo + tarefa única + benefício. É o tipo de alerta que faz o vendedor agir na hora.

04 AS 8 REGRAS DE PRODUTO — O QUE FALTA E COMO RESOLVER

Você tem razão: saber que existe a regra 10003 e não saber o nome dela não serve para nada.

O que temos com certeza: os parâmetros de cada regra (janela, limite, mínimo de pedidos), a contagem de produtos afetados e a lista dos produtos com os números.

O que não temos: o nome. Ele não está na API — fica no arquivo de tradução do painel da Shopee, que o navegador carrega separado.

E resolver isso custa 2 minutos, não uma investigação. No Seller Central, em Central de Dados → Diagnóstico de Produto, cada regra aparece com o nome escrito na tela e a contagem ao lado. Basta comparar as contagens que já temos com o que estiver escrito:
regra 10003 → 17 produtos
regra 10002 → 10 produtos
regra 10006 → 10 produtos
regra 10000 →  2 produtos
regra 10004 →  1 produto
regra 10005 · 10007 · 10008 → 0
As contagens são únicas — 17, 10, 10, 2, 1. Batendo os números com os títulos da tela, as 8 regras ficam nomeadas de uma vez e para sempre.
